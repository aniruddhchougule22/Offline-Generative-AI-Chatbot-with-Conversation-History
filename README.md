# Percentage Calculator with Admin/User Login

A simple web-based application built using HTML, CSS, and JavaScript. It allows users to register, log in, calculate percentages, and view their calculation history. The project also includes an admin dashboard for managing users and viewing activity logs.

## Project Overview

This project is designed for beginners to learn front-end web development concepts such as:

- Form handling
- Local Storage usage
- Role-based login access
- DOM manipulation
- Basic UI design and interactivity

## Objectives

- Provide a simple login and registration system
- Allow users to calculate basic and marks-based percentages
- Store user data and calculation history in browser storage
- Provide an admin panel for managing users and logs

## Features

- User registration and login
- Admin and user role-based access
- Basic percentage calculator
- Marks percentage calculator
- Calculation history saved locally
- Password hashing for better security
- Theme switching for better user experience
- Admin dashboard for viewing users and logs

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Browser Local Storage
- CryptoJS for password hashing

## Software Requirements

- Visual Studio Code
- Modern web browser such as Google Chrome, Microsoft Edge, or Mozilla Firefox
- Optional: Live Server extension for VS Code

## Installation Steps

1. Download or clone the project folder.
2. Open the folder in Visual Studio Code.
3. Open the desired HTML file in your browser.
4. For a better experience, run it with Live Server.

## How to Use

1. Open the login page from Index.html.
2. Register a new user account or log in with an existing one.
3. If you log in as a user, you can use the percentage calculator and view your history.
4. If you log in as an admin, you can manage users and view logs.

## Advantages

- Easy to use
- Beginner friendly
- Lightweight and fast
- No backend required
- Works offline using browser storage

## Limitations

- Uses browser Local Storage only
- No database integration
- No advanced user authentication system
- Data is stored locally on the device
